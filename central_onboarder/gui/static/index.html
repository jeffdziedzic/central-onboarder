Onboards new APs, switches, and gateways onto GLCP, New Central, and Classic Central.

This is not an official tool. It was created around a single environment's use case by an amateur coder. Use at your own risk.

General flow: set up Credentials, then build a Device List (import a CSV or add devices manually). Onboard adds devices to GLCP, assigns a subscription, and assigns the Central service. Pre-Provision assigns a Classic Central group. Once devices have actually checked into Central, Assign Site assigns their New Central site. See the user guide for more details.
