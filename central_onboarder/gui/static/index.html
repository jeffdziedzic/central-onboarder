Home

Onboards new APs, switches, gateways, and UXI sensors onto GLCP, New Central, Classic Central, and the UXI application.

This is not an official tool. It was created around a single environment's use case by an amateur coder. Use at your own risk.

General flow

  1. Set up Credentials
  2. Build a Device List (CSV or add manually)
  3. Onboard Devices adds devices to GLCP, assigns a subscription, assigns the service, and pre-provisions a Classic Central group, all in one Run Onboard Batch
  4. Once devices have checked into Central, Post Onboard assigns their New Central site and sets their hostname

See the user guide for more details.

Credentials

Stored locally in token.yaml (same format as the aruba_central project's token.yaml). Each account holds one customer's New Central/GLCP, Classic Central, and UXI settings. The account picked in the top bar is the one every screen uses, and the cards below edit it.

UXI Application

Not a credential - the GreenLake application_id (and region, if applicable) for the UXI application, used to assign UXI rows their service. Auto-discovery (like Central's) has nothing to find this from until at least one UXI sensor has been assigned once, so it needs to be entered here.

Wipe All Credentials

Removes every account in token.yaml, not just the selected one. Cannot be undone; you'll need to re-enter everything from scratch.

Onboard Devices

Adds every device not yet marked "GLCP" in the Device List to GLCP, assigns the Central service, and assigns a subscription (for rows with a Subscription Key set) - then assigns every row with a Target Group set, and not yet marked "Preprov.", to that group in Classic Central.

Add devices to GLCP, assign service, assign subscription, and assign target group (pre-provision), in that order.

Check Status

Looks up a device's full state across GLCP/New Central (in GLCP, service, subscription) and Classic Central (pre-provisioned group, site, checked in).

Manual: Add to GLCP

Needs both a Serial and a MAC per device, paired in order. Or check "Pull from Device List" to instead add every row not yet marked "GLCP" using each row's own Serial/MAC (Serial(s)/MAC(s) fields below are ignored in that mode).

Manual: Assign Service

Attaches to the Central application. Leave Application ID blank to auto-discover from another already-assigned device in this workspace. Or check "Pull from Device List" to instead assign every row not yet marked "Service" - UXI rows get the UXI application, everything else gets Central (Serial(s)/MAC(s) and Application ID fields below are ignored in that mode).

Manual: Assign Subscription

Check "Pull from Device List" to instead assign every row with a Subscription Key set and not yet marked "Sub.", using each row's own key (Serial(s)/MAC(s) and Subscription Key fields below are ignored in that mode).

Pre-Provision (Classic Central group)

Already included in Run Onboard Batch above. Assigns explicit devices to a group directly (Classic Central's API expects Serial(s) specifically; a MAC may not be accepted) - or check "Pull from Device List" to instead assign every row with a Target Group set and not yet marked "Preprov." to its own Target Group (Group/Serial(s) fields below are ignored in that mode), e.g. to retry just this step without repeating the GLCP steps.

Post Onboard

Manual steps - run these once you know the relevant devices have actually checked into Central. Assign Site first: a device has to be in a site or device group (provisioned in New Central) before its hostname can be set.

Assign Site

Assigns explicit serials to a site directly - doesn't require the devices to be tracked in the Device List. Or check "Pull from Device List" to instead assign every Device List row with a Target Site set, and not yet marked "Site", to its own Target Site (Serial(s)/Device Type/Site Name fields below are ignored in that mode).

Set Hostname

Sets each device's hostname in New Central (its own System Information profile, for APs, switches and gateways). The device must already be provisioned in New Central, in a site or device group. Tick "Set in Classic Central" for customers still on Classic: the device must have checked into Classic Central and be in a UI group (template groups are refused). Type serials and hostnames paired in order, or check "Pull from Device List" to instead set every row with a Hostname and not yet marked "Host." (UXI rows are skipped).
